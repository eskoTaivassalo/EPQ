# Demo-käsikirjoitus Parents & Teachers App

## 🎬 **Esittely-käsikirjoitus (5-10 min)**

### **1. Johdanto (30s)**
- "Tervetuloa Parents & Teachers -sovelluksen esittelyyn"
- "Globaali alusta opettajille ja vanhemmille"
- "Rakennettu React Native + Firebase"

### **2. Aloitusnäkymä (1 min)**
- Kolme roolia: Oppilas, Opettaja, Vanhempi
- Moderni käyttöliittymä
- Selkeä navigointi

### **3. Opettajan näkymä (2 min)**
- Kirjautuminen opettajana
- Dashboard ja tilastot
- **Profiilin luonti:**
  - Osaamisalueet
  - Hinnoittelu
  - Saatavuus
  - Verkko-/lähiopetus

### **4. Vanhemman näkymä (2 min)**
- Kirjautuminen vanhempana
- Opettajien hakutoiminto
- Suodattimet ja hakukriteerit
- Opettajaprofiilit ja arvostelut

### **5. Tekniset ominaisuudet (1 min)**
- Firebase-integraatio
- Reaaliaikainen tietokanta
- Kansainvälinen skaalautuvuus
- Turvallinen autentikointi

### **6. Tulevaisuuden visio (30s)**
- Video-puhelut
- Maksutoiminnot
- Kalenteritoiminnot
- Viestintätyökalut

## 🎯 **Keskeiset myyntivaltti**
1. **Globaali toimivuus** - Opettajat ympäri maailmaa
2. **Kolme käyttäjäroolia** - Kattava ratkaisu
3. **Moderni teknologia** - React Native + Firebase
4. **Skaalautuva** - Valmis kasvuun
5. **Käyttäjäystävällinen** - Intuitiivinen käyttöliittymä
